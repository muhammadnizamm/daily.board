# DailyBoard

DailyBoard adalah aplikasi untuk mengelola tugas dan catatan dalam satu dashboard.

## Fitur

* Menambahkan tugas
* Menghapus tugas
* Mengedit tugas
* Menandai tugas selesai
* Filter tugas
* Pencarian tugas
* Drag and drop tugas
* Penyimpanan menggunakan LocalStorage
* Menambahkan dan menghapus catatan
* Kutipan dari API
* Informasi cuaca
* Dark Mode
* Responsive untuk perangkat mobile

## Cara Menggunakan

1. Masukkan tugas pada kolom tugas.
2. Klik tombol **Tambah**.
3. Klik tugas untuk menandai tugas selesai.
4. Klik dua kali tugas untuk mengedit.
5. Klik **Hapus** untuk menghapus tugas.
6. Gunakan filter untuk melihat tugas sesuai status.
7. Masukkan nama kota untuk melihat cuaca.
8. Gunakan **Dark Mode** untuk mengubah tampilan.

## Struktur File

* `index.html` — halaman utama aplikasi
* `style.css` — mengatur tampilan dan responsive
* `script.js` — mengatur jalannya aplikasi
* `tugas.js` — mengatur fitur tugas
* `storage.js` — mengatur penyimpanan LocalStorage
* `api.js` — mengatur pengambilan data API
* `README.md` — dokumentasi project

## Responsive

DailyBoard menggunakan CSS Media Query agar tampilan dapat menyesuaikan dengan ukuran layar desktop, tablet, dan mobile.
